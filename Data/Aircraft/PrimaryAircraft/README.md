# Flying Trainer One Primary Aircraft

This package records the primary aircraft selected for CoreSim JSBSim
integration. The model is project-authored, unbranded, and does not claim
faithful equivalence to a named real aircraft type.

- CoreSim aircraft configuration: `core_sim/aircraft/flying_trainer_one/aircraft-config.json`
- JSBSim aircraft model: `core_sim/jsbsim/aircraft/flying_trainer_one/flying_trainer_one.xml`
- JSBSim piston engine model: `core_sim/jsbsim/engine/flying_trainer_one_piston.xml`
- JSBSim propeller model: `core_sim/jsbsim/engine/flying_trainer_one_propeller.xml`
- JSBSim reset state: `core_sim/jsbsim/aircraft/flying_trainer_one/reset00.xml`
- Validation evidence status: unvalidated until the aircraft validation suite passes
