# Tests

Native test boundary for CoreSim, Geo/Terrain, data pipeline and integration validation.

Current scope includes the repository smoke test, CoreSim fixed-step and replay
coverage, geodesy and terrain service tests, pilot data-pipeline package tests,
runway importer tests, and the M1 vertical-slice validation target.

Run the M1 vertical-slice suite with:

```sh
tools/validate_m1_vertical_slice.sh
```
